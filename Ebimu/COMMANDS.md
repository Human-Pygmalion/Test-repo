# EBIMU-9DOFV5 명령어 정리

출처: E2BOX `EBIMU-9DOFV5_rev3.pdf` (41쪽 SPECIFICATION 문서), 6장 COMMAND.
[E2BOX EBIMU-9DOFV5 매뉴얼 페이지](https://www.e2box.co.kr/entry/EBIMU9DOFV5-%EB%A7%A4%EB%89%B4%EC%96%BC) 에서 받을 수 있습니다.

이 문서는 매뉴얼을 읽고 옮겨 적은 것입니다. 실제 센서로 확인한 것이 아닙니다.

---

## 먼저 알아야 할 것

### 1. 모든 설정은 자동으로 저장된다

매뉴얼의 거의 모든 명령 설명 끝에 같은 문장이 붙어 있습니다.

> 설정된 내용은 내부 비휘발성 메모리에 자동 저장 됩니다.

**전원을 껐다 켜도 되돌아오지 않습니다.** 되돌리려면 반대 명령을 직접 보내거나
`<lf>` (공장 초기화) 를 써야 합니다. 명령을 보내기 전에 지금 설정을 `<cfg>` 로
확인해 두세요.

### 2. 명령 형식

```
<명령어 데이터>       예: <sog1>   <sod2>   <sor10>
```

`<ok>` 응답이 온 뒤부터 설정된 값으로 동작합니다.
(`<ver>` 만 예외적으로 `<ok>` 를 응답하지 않습니다.)

### 3. 값이 항상 0=끄기 / 1=켜기 는 아니다

| 형태 | 명령 | 값의 뜻 |
| --- | --- | --- |
| 켜기/끄기 | `sog` `som` `sot` `sots` | `0` 끄기 / `1` 켜기 |
| 모드 선택 | `sod` | `0` 끄기 / `1` Local / `2` Global |
| 모드 선택 | `soa` | `0` 끄기 / `1`~`3` 가속도 / `4`~`5` 속도 |
| 모드 선택 | `sof` `soc` | `1` / `2` 중 하나 (끄기 없음) |
| 3단계 | `sem` | `0` OFF / `1` ON / `2` 능동형 ON |
| 수치 | `sor` `raa_t` `sff` 등 | 숫자 자체가 값 (Hz, ms, 계수) |

## 출력 순서

패킷은 `*` 로 시작하고 값을 `,` 로 구분해 `CR LF` 로 끝납니다.
켜 놓은 항목이 **아래 순서대로** 이어 붙습니다.

```
*<sof><sog><soa><som><sod><sot><sots>(CR)(LF)
```

| 순서 | 명령 | 항목 | 필드 수 |
| --- | --- | --- | --- |
| 1 | `sof` | 자세 (Euler 또는 Quaternion) | 3 또는 4 |
| 2 | `sog` | 자이로 x, y, z | 3 |
| 3 | `soa` | 가속도 **또는** 속도 x, y, z | 3 |
| 4 | `som` | 지자기 x, y, z | 3 |
| 5 | `sod` | 거리 x, y, z | 3 |
| 6 | `sot` | 온도 | 1 |
| 7 | `sots` | 타임스탬프 | 1 |

자세(`sof`)는 **끌 수 없습니다.** 항상 나옵니다.
자이로, 가속도, 지자기, 거리, 온도, 타임스탬프만 ON/OFF 됩니다.

예) `<sog1> <soa1> <sot1>` 을 켰다면 → 자세 3 + 자이로 3 + 가속도 3 + 온도 1 = **10개**

```
*-25.46,47.24,-35.77(CR)(LF)      # Euler 만 (기본값, 3개)
Roll -25.46도, Pitch 47.24도, Yaw -35.77도
```

## 6-1. 출력 명령 (OUTPUT COMMAND)

| 명령 | 값 | 뜻 | 기본값 |
| --- | --- | --- | --- |
| `<sb_>` | `1`~`8` | Baudrate — `1` 9600 / `2` 19200 / `3` 38400 / `4` 57600 / `5` 115200 / `6` 230400 / `7` 460800 / `8` 921600 | `5` (115200) |
| `<sor_>` | `1`~`1000` | 출력 주기 = 1ms × 값 (`10` = 10ms = 100Hz). `0` 은 polling 모드 | `10` |
| `<soc_>` | `1` `2` | `1` ASCII 출력 / `2` HEX(binary) 출력 | `1` |
| `<sof_>` | `1` `2` | `1` Euler Angles (Roll, Pitch, Yaw) / `2` Quaternion (z, y, x, w) | `1` |
| `<sog_>` | `0` `1` | 자이로(각속도) 출력 안함 / 출력 | `0` |
| `<soa_>` | `0`~`5` | 아래 표 참고 | `0` |
| `<som_>` | `0` `1` | 지자기 출력 안함 / 출력 | `0` |
| `<sod_>` | `0` `1` `2` | 거리 출력 안함 / Local / Global | `0` |
| `<sot_>` | `0` `1` | 온도 출력 안함 / 출력 | `0` |
| `<sots_>` | `0` `1` | 타임스탬프 출력 안함 / 출력 | `0` |

### `<soa_>` — 가속도와 속도는 같은 자리를 쓴다

| 값 | 뜻 | 단위 |
| --- | --- | --- |
| `0` | 출력 안함 (기본값) | |
| `1` | 중력성분 **포함** 가속도. 가만히 둬도 중력방향으로 1g 가 나옴 | g |
| `2` | 중력성분 **제거** Local 가속도 (센서 x,y,z축 기준) | g |
| `3` | 중력성분 **제거** Global 가속도 (동서남북/위아래 기준) | g |
| `4` | Local 속도 | m/s |
| `5` | Global 속도 | m/s |

**가속도와 속도를 동시에 볼 수 없습니다.** 명령이 하나뿐이라 둘 중 하나만 고릅니다.

### 값의 자릿수

| 항목 | 소수점 | 단위 | HEX 모드에서 나눌 값 |
| --- | --- | --- | --- |
| Euler | 2자리 | 도 (Roll ±180, Pitch ±90, Yaw ±180) | 100 |
| Quaternion | 4자리 | — | 10000 |
| 가속도 | 3자리 | g (1g = 9.81m/s²) | 1000 |
| 속도 | 3자리 | m/s | 1000 |
| 지자기 | 1자리 | uT (최대 ±3000uT) | 10 |
| 거리 | 3자리 | m | 1000 |
| 온도 | 1자리 | ℃ | 10 |
| 타임스탬프 | — | ms (0~60000 후 0 으로 돌아감) | — |

거리는 `/` (0x2F) 를 보내면 누적값이 0 으로 reset 됩니다.

## 6-2. 센서 명령 (SENSOR COMMAND)

| 명령 | 값 | 뜻 | 기본값 |
| --- | --- | --- | --- |
| `<sem_>` | `0` `1` `2` | 지자기센서 OFF / ON / **능동형 ON**(자기장 왜곡방지) | `2` |
| `<ssg_>` | `2`~`5` | 자이로 감도 — `2` 250dps / `3` 500dps / `4` 1000dps / `5` 2000dps | `5` |
| `<ssa_>` | `1`~`4` | 가속도 감도 — `1` 2g / `2` 4g / `3` 8g / `4` 16g | `4` |
| `<lpfg_>` | `0`~`7` | 자이로 LPF — `0` 16Hz / `1` 25 / `2` 34 / `3` 53 / `4` 73 / `5` 121 / `6` 180 / `7` 없음 | `4` |
| `<lpfa_>` | `0`~`7` | 가속도 LPF (값은 `lpfg` 와 같음) | `4` |
| `<sff_>` | `1`~`50` | 가속도+지자기 Filter Factor. 클수록 보정 빠름, 정밀도는 떨어짐 | `10` |
| `<sffa_>` | `1`~`50` | 가속도만 Filter Factor | `10` |
| `<sffm_>` | `1`~`50` | 지자기만 Filter Factor | `10` |
| `<raa_t_>` | `0`~`2000000000` | RAA Timeout (ms). 가감속에 따른 roll/pitch 오차 보정. `0` 이면 OFF | `10000` |
| `<rha_t_>` | `0`~`2000000000` | RHA Timeout (ms). 자기장 간섭에 따른 yaw 오차 보정. `0` 이면 OFF | `10000` |
| `<agc_e_>` | `0` `1` | 자이로 자동 캘리브레이션(AGC) OFF / ON | `1` |
| `<avcg_e_>` | `0` `1` | 자이로 AVC(능동 진동제거) OFF / ON | `0` |
| `<avca_e_>` | `0` `1` | 가속도 AVC OFF / ON | `0` |
| `<posf_sl_>` | `0.0000`~`1.0000` | position filter SL. `0` 이면 필터 비활성 | `0.02` |
| `<posf_st_>` | `0`~`1000` | position filter ST. `0` 이면 비활성 | `0` |
| `<posf_sr_>` | `0.0000`~`1.0000` | position filter SR. `0` 이면 비활성 | `0` |
| `<posf_ar_>` | `0.0000`~`1.0000` | position filter AR. `1` 이면 비활성 | `1` |
| `<posz>` | — | 누적된 속도/거리를 0 으로 | — |

RAA/RHA Timeout 은 **센서의 최대 가감속 시간보다 크게** 잡는 것이 좋습니다.

## 6-3. 캘리브레이션 명령 (CALIBRATION COMMAND)

**센서를 규정된 방법으로 직접 움직여야 합니다.** 결과는 자동 저장됩니다.

| 명령 | 뜻 | 사람이 해야 하는 것 |
| --- | --- | --- |
| `<cg>` | 자이로 캘리브레이션 | 움직임 없는 정지 상태로 두고, `<ok>` 까지 약 2초 대기 |
| `<caf>` | 가속도 정밀 캘리브레이션 | 명령 후 센서를 조금씩 돌려 `.` 이 여러 각도에서 나오게 함. 직육면체의 6면·12모서리·8꼭지점이 바닥을 향하게 하면 정밀해짐. 끝나면 `>` 전송 |
| `<cas>` | 가속도 간단 캘리브레이션 | 지표면과 수평인 정지 상태에서 명령 한 번 |
| `<cmf>` | 지자기 캘리브레이션 (권장) | 명령 후 전방위로 자유롭게 충분히 회전. 끝나면 `>` 전송. 이걸 쓰면 `cnxy`/`cnz` 는 필요 없음 |
| `<cnxy>` | 지자기 XY축 | z축을 하늘로 향하게 → 1초 대기 → 가로로 180도 회전 → `>` 전송 |
| `<cnz>` | 지자기 Z축 | y축을 하늘로 향하게 → 1초 대기 → 가로로 180도 회전 → `>` 전송 |
| `<+cnxy>` `<+cnz>` | 위와 같되 `cmf` 결과에 **더해서** 적용 | (`+` 없이 쓰면 `cmf` 데이터가 삭제됨) |
| `<cmo>` | 전방위 자세 OFFSET 설정 — `<` 입력 순간의 자세가 원점이 됨 | 원하는 자세로 맞춘 뒤 명령 |
| `<cmox>` `<cmoy>` `<cmoz>` `<cmoxy>` | roll / pitch / yaw / roll+pitch 축만 offset | 위와 같음 |
| `<cmco>` | 설정된 offset 전부 제거 | — |

지자기 캘리브레이션은 **자기장 간섭이 없는, 실제 사용할 환경에서** 해야 합니다.

## 6-4. 기타 명령 (ETC COMMAND)

| 명령 | 뜻 | 주의 |
| --- | --- | --- |
| `<cfg>` | **현재 설정을 명령어별로 전부 출력** | `>` 를 입력할 때까지 센서가 정지 상태로 있음 |
| `<ver>` | 버전 확인. 응답 예 `<imu9dofv500>` | 이 명령만 `<ok>` 를 응답하지 않음 |
| `<pons_>` | 전원 인가 시 작동 여부 — `0` 작동 안함 / `1` 작동함 | `0` 으로 두면 전원을 넣어도 데이터가 안 나옴 |
| `<start>` | 센서를 작동 상태로 | |
| `<stop>` | 센서를 작동 중지 상태로 | 데이터 출력이 멈춤 |
| `<lf>` | **공장 초기화** — 출하시 설정값으로 전부 복원 | 캘리브레이션 결과까지 사라짐 |
| `<reset>` | 센서 reset. 전원 재인가와 같은 동작 | |

### `<cfg>` 로 지금 설정 확인하기

출력 항목이 무엇이 켜져 있는지 알고 싶을 때 **가장 확실한 방법**입니다.
설정을 바꾸지 않으므로 안전합니다.

```bash
python3 Ebimu_cmd.py -p /dev/ttyUSB0 --shell
  cmd> <cfg>
```

`>` 를 보낼 때까지 센서가 정지 상태로 있으므로, 확인이 끝나면 `>` 를 보내야 합니다.

## 이 저장소 코드에 반영한 내용

`Ebimu_cmd.py` / `Ebimu_live.py` 는 매뉴얼을 구하기 전 추정으로 만든 부분이 있었고,
아래와 같이 고쳤습니다.

| 고치기 전 | 지금 |
| --- | --- |
| `<soe1>` 로 Euler 켜기 | 그런 명령 없음. `<sof1>` 로 포맷만 선택, 자세는 끌 수 없음 |
| `<soq1>` 로 Quaternion 켜기 | `<sof2>` |
| `<sov1>` 로 속도 켜기 | `<soa4>` / `<soa5>`. 가속도와 동시에 못 씀 |
| 속도가 거리 뒤에 나온다고 봄 | 속도는 `soa` 자리(3번째) |
| 존재하지 않는 `id` 항목 | 삭제 |
| `<sod1>` = 거리 켜기 | `1` Local / `2` Global 구분 |
| 타임스탬프 단위를 초로 표시 | ms |
| 위험 명령 목록에 `<fd>` `<rst>` | `<lf>` `<sb>` `<reset>` `<stop>` `<pons>` |
| 캘리브레이션 목록에 `<cn` 없음 | `<cnxy>` `<cnz>` `<+cn..>` 포함 |
| "전원을 껐다 켜면 원래대로" | 자동 저장됨을 명시 |
| `--detect` 가 항목을 껐다 켜서 판정 | `<cfg>` 로 읽어서 판정 (설정을 바꾸지 않음) |

`--detect` 가 가장 크게 바뀌었습니다. 설정이 자동 저장되므로 껐다 켜는 방식은
중간에 끊기면 되돌릴 수 없습니다. 지금은 `<cfg>` 로 읽는 것이 기본이고,
껐다 켜는 방식은 `--detect --toggle` 로 남겨 두되 실행 전에 확인을 받습니다.

`<cfg>` 응답 형식은 매뉴얼에 "명령어별로 출력합니다" 라고만 되어 있고 예시가 없어,
`<sog1>` 처럼 `<명령값>` 으로 온다고 보고 파싱합니다. 형식이 다르면 받은 내용을
그대로 화면에 찍고 `--toggle` 을 안내합니다.
